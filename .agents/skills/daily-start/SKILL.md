# 每日开场

用最少步骤确定今天最重要的一件事。

## 流程

1. 读取最近一篇 Daily、当前 Weekly 和 `10-Action/11-Focus-聚焦承诺/`；缺失时如实说明。
2. 用一段话概括仍在推进的上下文，区分文件事实与 Agent 建议。
3. 只问一个问题：今天结束前，哪一件事推进了就算值得？
4. 用户不确定时，基于现有 Focus 或 Active 给不超过三个可直接回复的候选。
5. 用户明确回答后，展示将写入今日日志的预览；得到确认后再创建或更新 `## 今日重点`，不覆盖其他正文。

## 边界

- 不自动新建目标、项目或任务。
- 不把建议写成用户承诺。
- 不因缺少周计划而编造计划。
- 写入前读取 `30-Time/README.md` 和日志模板。
