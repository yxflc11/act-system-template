# 收件箱分诊

`x/` 是待处理 Raw Source。分诊只帮助判断，不改变来源。

## 流程

1. 读取 `x/README.md`，列出顶层待处理文件；忽略 README 和隐藏文件。
2. 对每项记录：文件名、来源类型、主题、完整度、潜在价值和缺失信息。
3. 给出建议之一：保留待处理、进入 Ingest、转为行动候选、需要用户补充、可考虑归档。
4. 最后按优先级列出最值得先处理的少量项目，并说明理由。

## 边界

- 不编辑、重命名、移动或删除 Raw。
- 不把剪藏内容声明为用户观点。
- 不为不完整来源编造作者、日期、结论或链接。
- 需要改变文件时，转交 `inbox-archive` 并等待用户确认具体清单。
