# Markdown 模板生成

根据用途给出最小可用结构，让用户能立刻填写。

## 做法

1. 判断内容属于学习笔记、项目拆解、工作记录、复盘、文章或其他明确类型。
2. 只保留会改变写作结果的栏目；通常 3—7 个区块足够。
3. 用 `___`、提示句或问题作为占位，不预填未经用户确认的结论。
4. 默认先在对话中展示。只有用户明确指定路径并要求保存时才创建文件。
5. 保存前遵守目标文件夹 README 和 frontmatter 规则。

## 输出要求

- 标题具体，栏目名称使用用户的语言。
- 模板应能单独阅读，不依赖本次对话。
- 不加入虚构来源、日期、负责人、截止时间或完成状态。
- 如果用户已有正文，优先保留原文并只补结构。
