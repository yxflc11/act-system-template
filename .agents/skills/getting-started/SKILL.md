# ACT 首次激活

目标是让空壳产生一条真实、可验证的使用链路，不替用户编造身份、目标或笔记。

## 流程

1. 先读 `README.md`、`AGENTS.md` 和 `00-开始使用.md`。
2. 确认这是公开模板的本地副本，并提醒 USER、MEMORY、日志、任务和知识卡不会提交。
3. 请用户提供最少的本地资料：称呼、时区和当前想用 ACT 处理的一件事。得到明确回答后，才创建被 `.gitignore` 排除的 `.claude/USER.md`。
4. 帮用户选择一个真实入口：
   - 在今日日志记录一个重点；
   - 向 `x/` 放入一条原始来源；
   - 从 `20-Card/index.md` 发起一次 Query。
5. 完成后运行只读 Schema 检查，并告诉用户下一句可以说什么。

## 边界

- 不生成虚构的愿景、身份、目标、任务或知识卡。
- 不把公开示例当成用户事实。
- 不修改 `10-Action/` 或 `30-Time/` 中的承诺，除非用户明确确认。
- 不上传、发布或连接外部服务，除非用户另行授权。
