# 文件类型约定

## Frontmatter 规则

**普通知识笔记与索引卡**：只写以下两个必需属性：

```yaml
---
创建日期: YYYY-MM-DD
AI 备注: 一句话摘要
---
```

**核心卡例外**：除上述两个必需属性外，可选填 `index`；只能链接 `21-IndexCard-索引卡/` 中已存在的索引卡。主题归属以索引卡正文为准，`index` 不作为第二套权威清单。

**时间笔记例外**：日志和周记沿用极简模板，可只写 `已回顾: false`，不强制补普通知识笔记属性。

**任务笔记例外**：`10-Action/` 下可使用任务工作流需要的 `tags`、`deadline`、`project`、`up`、`relate` 等字段。

---

## 各类文件命名一览

| 文件类型 | 命名格式 | 示例 |
|---------|---------|------|
| 日志 | `YYYY-MM-DD（周几）.md` | `2026-06-05（五）.md` |
| 周记 | `YYYY-Wxx.md` | `2026-W23.md` |
| 12 周目标 | `<YY>Y<n>-描述.md`（两位年份 + Y + 周期序号） | `26Y1-完成课程制作.md` |
| 愿景信 | 自由命名 | `愿景信-2026.md` |
| 任务文件 | `YYMM-描述.md` | `2603-王总-Q3策略方案.md` |
| 核心卡 | `主题-描述.md` | `笔记系统-最小闭环体验.md` |
| 阅读卡 | `B编号-书名.md` | `B003-卡片盒笔记法.md` |
| 主题索引卡 | `K编号-关键词.md` | `K102-笔记管理.md` |
| 人物索引卡 | `p-姓名.md` | `p-Esor Huang.md` |

---

## 不要做的事

- 不要在核心卡 frontmatter 里加 `tags`、`type`、`category`、`project` 等额外字段
- 不要在索引卡 frontmatter 里保留 `up`、`relate`、`tags`、`created`、`source`、`project` 等模板空字段；关系写进正文
- 不要自行新建索引卡双链（`index` 属性只填已有的索引卡）
- 不要在模板外的笔记里加 callout 框架或 checklist（日志/周记）
