# 收件箱归档

先给方案，再执行用户明确确认的项目。

## 流程

1. 读取 `x/README.md` 和相关目标文件夹 README。
2. 对每个待处理文件给出建议去向、拟用名称和理由，并标明是否保留 Raw。
3. 让用户确认具体项目；“全部处理”只有在清单已完整展示时才有效。
4. 执行前检查目标不存在，避免覆盖。
5. 保留原始内容。若要生成 Wiki 摘要或行动候选，必须另建衍生文件并清楚引用 Raw。
6. 完成后列出实际移动、创建和未处理的项目。

## 边界

- 不触碰 `30-Time/34-Daily-日志/` 或 `笔记同步助手/`。
- 不删除有意义内容，不覆盖同名文件。
- 不把 Raw 的观点改写成用户观点。
- 涉及 Action、Time、语义冲突或删除时，需要单独确认。
