# 每日收场

产出一段短而真实的日终记录，不写绩效报告。

## 流程

1. 读取今日日志中的重点和正文，以及与它直接相关的现有 Action。
2. 依次确认四项：推进了什么、学到什么、卡在哪里、明天从哪里接上。已有答案不要重复追问。
3. 区分用户原话、文件事实和 Agent 归纳；不把归纳冒充用户判断。
4. 生成收尾预览，保留用户措辞。
5. 只有用户明确确认后，才追加到 `## 今日总结`；不得覆盖用户已有正文。

## 边界

- 不自动完成、移动或新建 Action。
- 不因今天没完成而改写目标。
- 发现值得进入 Wiki 的内容时只给 Ingest 建议，不静默创建卡片。
- 若用户不想保存，结束对话且不写文件。
